Car Service — Frontend

This is a minimal Vite + React scaffold for the Car Service project.

Getting started (PowerShell):

```powershell
cd C:\Users\manik\Downloads\car-service\car-service\frontend
npm install
npm run dev
```

The dev server runs on http://localhost:3000 by default. To build for production:

```powershell
npm run build
npm run preview
```

If you want the frontend to talk to the backend, set up a proxy in `vite.config.js` (example: proxy `/api` to `http://localhost:8081`).
